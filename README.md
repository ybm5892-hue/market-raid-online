# MARKET RAID ONLINE

브라우저에서 실행하는 무료 투자 분석팀 토론 아레나입니다.

## 웹사이트 공개하기

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 **main**, 폴더를 **/(root)**로 설정하고 **Save**를 누릅니다.
4. GitHub Pages가 사이트를 배포하면 아래 주소에서 접속할 수 있습니다.

https://ybm5892-hue.github.io/market-raid-online/

## 기능 및 한계

- TradingView 종목 차트 임베드
- 데모 모드
- 브라우저에서 공개 AI 모델을 실행하는 선택 기능(WebGPU 필요; 최초 실행 시 대용량 모델 다운로드)
- 두 모델의 독립 분석, 교차 검토, 최종 의장 보고
- 보고서 복사 및 TXT 저장

유료 AI API 키는 필요하지 않습니다. 실제 AI 회의에는 호환 가능한 최신 Chrome/Edge, WebGPU 및 충분한 메모리가 필요합니다. 무료 차트는 거래소별로 지연될 수 있습니다. AI 모델은 임베드된 차트나 외부 뉴스 본문을 직접 읽지 않으므로 사용자가 입력한 가격/맥락과 별도 링크에서 직접 확인한 자료에 의존합니다.

이 프로젝트는 투자 교육 및 리서치 보조용이며 수익을 보장하지 않습니다.
