# MARKET INTEL — iPhone 투자 분석실

## iPhone 실행
1. Safari에서 https://ybm5892-hue.github.io/market-raid-online/ 를 엽니다.
2. 공유 메뉴 → 홈 화면에 추가를 선택합니다.
3. 홈 화면 아이콘으로 실행합니다. 홈 화면 앱과 일부 정적 화면은 캐시되지만 뉴스·가격·AI 회의에는 인터넷이 필요합니다.

## 시스템 흐름
1. Google News RSS 공개 피드에서 종목 뉴스 및 거시경제 뉴스 제목/스니펫을 수집합니다.
2. Yahoo Finance chart endpoint 공개 데이터로 일봉 이력을 가져와 SMA20/50/200, RSI14, MACD, 거래량 배수 및 최근 고저점을 계산합니다.
3. 거시경제, 뉴스/산업, 기술적 분석, 리스크 담당 AI가 역할별 보고서를 작성합니다.
4. 내부 토론 AI가 보고서의 공통점, 이견, 반박 및 추가 검증 항목을 작성합니다.
5. 팀장이 최종 결론, 시나리오, 진입·철회 조건, 자료 한계를 보고합니다.

## 무료 AI
- https://openrouter.ai/settings/keys 에서 API 키를 만듭니다.
- 기본 라우터는 `openrouter/free`입니다. 무료 모델을 무작위 선택하며 모델 가용성은 달라집니다.
- OpenRouter Free는 무료이지만 현재 공개 한도는 일반적으로 20회/분, 일일 50회 요청입니다. 제공자별 제약이 추가될 수 있습니다. 여섯 번의 모델 호출로 회의가 진행됩니다.
- 실제 OpenAI GPT 모델을 무료로 제공하는 것은 아닙니다. OpenAI GPT를 직접 호출하면 사용료가 발생할 수 있습니다.
- 키는 코드에 하드코딩하지 않습니다. 브라우저 세션 저장소에만 두며 공유 기기에서 사용하지 마세요.
- 종목/뉴스 맥락은 AI 제공자에게 전달됩니다. 계좌번호, 개인정보, 비공개 정보는 입력하지 마세요.

## 자료 정확성 제한
- 뉴스는 Google News RSS를 공개 CORS 프록시를 통해 조회합니다. 프록시나 RSS 접근이 차단될 경우 뉴스 수집은 실패할 수 있으므로 직접 검색 및 수동 입력을 제공합니다.
- 차트는 TradingView 위젯이며, 자동 계산 지표는 Yahoo Finance 공개 가격 이력에 기반합니다. Yahoo 데이터 접근이 CORS 프록시에서 거부될 수 있습니다.
- 뉴스 수집이 성공하지 않았다고 해서 관련 뉴스가 없다는 뜻은 아닙니다.
- 차트 iframe 화면을 AI가 직접 읽는 것은 아닙니다. AI는 수집한 뉴스 제목/스니펫과 지표 계산 결과를 입력으로 받습니다.
- 시간 지연, 기업행동 조정, 제공자 누락 등이 있을 수 있습니다. 원문과 시세를 별도로 검증하세요. 투자 자문 및 수익 보장 도구가 아닙니다.
