# MARKET INTEL — iPhone 투자 분석실

실행 주소: https://ybm5892-hue.github.io/market-raid-online/

## iPhone 홈 화면에 설치
1. Safari에서 위 실행 주소를 엽니다.
2. 공유 버튼 → 홈 화면에 추가를 누릅니다.
3. 추가된 MARKET INTEL 아이콘을 홈 화면에서 실행합니다.

## 회의 시작
1. 티커를 선택합니다 (예: NVDA, SOXL, QQQ, 삼성전자 005930.KS).
2. OpenRouter에서 무료 API 키를 발급합니다: https://openrouter.ai/settings/keys
3. 사이트의 '무료 AI API 키' 입력 영역에 키를 붙여넣습니다.
4. '전문가 회의 시작 · 팀장 보고서 받기'를 누릅니다.
5. 자료를 수집한 다음 거시경제, 뉴스·산업, 기술적 분석, 리스크 전문가가 개별 분석합니다. 내부 토론을 거쳐 팀장이 최종 보고서를 냅니다.

## 자료의 출처와 한계
- 최신 뉴스: Google News RSS 공개 피드의 기사 제목·요약·발행 일자·원문 링크를 수집합니다.
- 차트: TradingView 위젯을 보여 줍니다.
- 계산 지표: Yahoo Finance 공개 가격 이력으로 SMA20/50/200, RSI(14), MACD, 거래량 배수, 20/60거래일 고저점 등을 계산합니다.
- 외부 RSS/가격 자료는 공개 CORS 프록시를 통해 접근하므로 프록시가 실패하거나 제공자 접근이 제한되면 자동 수집에 실패할 수 있습니다. Google News 직접 검색 링크와 수동 뉴스 입력 필드를 사용할 수 있습니다.
- AI는 차트 iframe 자체를 볼 수 없으며, 수집한 기사 스니펫과 앱에서 계산한 정량 지표를 입력으로 분석합니다.
- 자료가 오래되거나 누락될 수 있습니다. 원문, 발표 시각, 원시 시세를 별도로 확인하세요.

## 무료 AI 및 개인정보
- 기본 모델 라우터: OpenRouter `openrouter/free`. 사용 가능한 무료 모델을 라우터가 선택하므로 사용되는 모델/가용성은 변할 수 있습니다.
- 무료 이용은 실제 OpenAI GPT 사용과 다릅니다. GPT API를 직접 이용하면 비용이 발생할 수 있습니다.
- 무료 모델은 계정 및 제공자 한도에 따라 제한됩니다. 회의는 총 6개 AI 호출(4개 독립 분석, 내부 토론, 팀장 보고서)을 사용합니다.
- API 키는 소스 코드에 넣지 않고 이 브라우저의 세션 저장소에만 넣습니다. 공용 기기에서 사용하지 마세요. 키를 다른 사람에게 공유하지 마세요.
- 종목과 분석 맥락은 OpenRouter의 선택된 AI 제공자에게 전달될 수 있습니다. 계좌번호, 개인정보, 비공개 정보를 입력하지 마세요.
