# MARKET RAID · iPhone edition

## iPhone에서 열기
1. Safari에서 https://ybm5892-hue.github.io/market-raid-online/ 를 엽니다.
2. 공유 버튼(네모에서 위쪽 화살표)을 누릅니다.
3. **홈 화면에 추가**를 선택합니다. 필요하면 "웹 앱으로 열기"를 켭니다.
4. 홈 화면의 MARKET RAID 아이콘에서 실행합니다.

## 무료 AI 회의
- OpenRouter 계정을 만들고 무료 모델용 API 키를 발급합니다: https://openrouter.ai/settings/keys
- 앱에서 키를 입력하면 OpenRouter의 `openrouter/free` 라우터가 사용 가능한 무료 모델에 요청을 전달합니다.
- 모델/제공자와 무료 한도는 달라질 수 있습니다. 무료 요금제는 요청 한도가 있고 API 가용성을 보장하지 않습니다.
- 이는 OpenAI GPT 모델 자체가 아닙니다. GPT 모델은 별도 유료 API 요금이 발생할 수 있습니다.
- API 키는 HTML 저장소에 하드코딩하지 않습니다. 브라우저 탭 세션에만 저장합니다. 공개 기기에서는 키를 입력하지 마세요.
- 입력한 투자 맥락은 AI 제공자에게 전달될 수 있으므로 계좌정보, 개인정보, 비공개 재무정보를 붙여넣지 마세요.

## 기능 / 제한
- 두 팀(ORBIT / LANTERN)의 독립 분석, 반박, 재검토 및 의장 최종 보고서
- 데모 모드는 API 호출 없이 실행 가능
- 보고서 복사 / TXT 저장
- 실시간 시세·뉴스는 자동 수집하지 않습니다. 현재가, 등락률, 뉴스는 이용자가 직접 확인해 입력해야 합니다.
- iPhone Safari에서 인터넷 연결이 필요합니다. 앱 UI 일부는 캐시되지만 AI 요청은 오프라인에서 동작하지 않습니다.
